# -ML-Capstone-Project

## 📌 Project Overview
This project is a complete Machine Learning pipeline covering:
- Data preprocessing and exploratory data analysis (EDA)
- Regression modeling using linear regression
- Classification modeling using logistic regression
- Clustering using unsupervised learning using K-means 
- Model evaluation and result analysis

The goal is to demonstrate a clear understanding of machine learning workflows in a reproducible and well-documented manner.

---

## 📊 Dataset
**Dataset Name:** Heart Disease Prediction Dataset  
**Source:** Kaggle  
**Description:**  
The Heart Disease dataset is a medical dataset commonly used for machine learning tasks related to
cardiovascular disease prediction. It contains clinical and demographic information about patients and is
suitable for classification, regression, and clustering tasks . The dataset contains medical attributes used to predict
the presence or absence of heart disease in patients.

- Rows: ~300
- Features: 14 (Numerical and categorical)
- Target column (Classification): `target`

• Numerical Features: age, trestbps, chol, thalach, oldpeak
• Binary Features: sex, fbs, exang, target
• Categorical Features (encoded numerically): cp, restecg, slope, ca, thal


---

## 🧠 Models Implemented
### 1️⃣ Regression
- Model: Linear Regression
- Task: Predict a continuous variable
- Evaluation Metrics:
  - MSE
  - RMSE
  - R² Score

### 2️⃣ Classification
- Model: Logistic Regression
- Task: Predict presence/absence of heart disease
- Evaluation Metrics:
  - Accuracy
  - Confusion Matrix
  - Precision & Recall

### 3️⃣ Clustering
- Model: K-Means
- Task: Group patients based on features
- Evaluation Metrics:
  - Elbow Method
  - Silhouette Score
